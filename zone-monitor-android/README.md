# Keytrins Zone Monitor 0.1.1

Android-приложение для визуального контроля сильных ценовых зон на M15. Оно не подключается к торговому счёту, не хранит пароль брокера и не открывает сделки.

## Что отображается

- свечной график последних 120 баров;
- поддержки, сопротивления, зоны смены роли и проторговки;
- сила зоны `Q0–Q100`;
- ближайшие поддержка и сопротивление;
- отдельная маркировка источника котировок.
- масштаб свечей жестом двумя пальцами и горизонтальная прокрутка истории;
- полноэкранный график с поддержкой поворота телефона;
- двойное касание или кнопка `1:1` для сброса масштаба;
- подписи близких зон автоматически разрежаются, чтобы не накладываться друг на друга.

## Источники данных

1. **Demo** — встроенные демонстрационные свечи, работает сразу и помечен как `DEMO`.
2. **Twelve Data** — внешние котировки M15. API key вводится на телефоне и шифруется Android Keystore. Этот feed может немного отличаться от котировок конкретного брокера MT5.
3. **MT5 Bridge** — точный режим для свечей из desktop/VPS-терминала. Приложение запрашивает URL вида `https://host/path?symbol=EURUSD&timeframe=M15&limit=320`.

Минимальный ответ Bridge:

```json
{
  "updated_at": "2026-09-02 12:00 UTC",
  "candles": [
    {"time": 1788350400, "open": 1.08710, "high": 1.08760, "low": 1.08690, "close": 1.08742, "volume": 212}
  ]
}
```

Нужно не менее 80 свечей. Поле `time` — Unix seconds или milliseconds. Если Bridge дополнительно возвращает массив `zones`, приложение использует серверные зоны:

```json
{"zones":[{"low":1.08480,"high":1.08520,"score":88,"type":"SUP","touches":5,"acceptance_bars":22}]}
```

Допустимые типы: `SUP`, `RES`, `FLIP`, `TRADE`, `ACTIVE`.

## Сборка

Проект использует Android Gradle Plugin 8.7.3, Gradle 8.9, Java 17, minSdk 26 и targetSdk 35. В репозитории нет API-ключей и ключа подписи APK.
